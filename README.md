## Que es Calculadora de Reticula Editorial

Calculadora de Reticula Editorial permite experimentar con la construccion de una reticula editorial usando dimensiones reales. Desde una misma interfaz puedes elegir el papel, modificar margenes, definir columnas y cambiar el intercolumnado para comprobar inmediatamente su efecto sobre la organizacion y el ritmo visual de la pagina.

Esta herramienta esta dirigida especialmente a estudiantes y docentes de diseno editorial, asi como a quienes necesitan consultar rapidamente una estructura antes de preparar una maqueta o un documento para impresion. Su planteamiento didactico conecta los fundamentos de la reticula con un flujo de trabajo cercano a Adobe InDesign, incluyendo conversiones y equivalencias del sistema tipografico.

## Funcionalidades principales

- Representacion y calculo instantaneo de reticulas editoriales.
- Seleccion de formatos de papel predeterminados o introduccion de medidas propias.
- Controles para margenes, columnas, medianiles y reticula base.
- Canvas interactivo con capas cuya visibilidad puede alternarse.
- Conversion entre las unidades tipograficas PostScript/DTP y Didot.
- Explicaciones incorporadas para interpretar los distintos parametros.
- Equivalencias pensadas para facilitar el trabajo en InDesign.
- Experiencia de pagina unica, sin interrupciones entre las distintas tareas.

## Como utilizarla

1. Elige uno de los formatos disponibles o introduce manualmente el tamano del papel.
2. Define los margenes, el numero de columnas, los medianiles y la reticula base.
3. Revisa el canvas para analizar como queda distribuida la pagina.
4. Activa o desactiva las capas para contrastar estructuras y comprobar proporciones.
5. Consulta las equivalencias tipograficas si alternas entre PostScript/DTP y Didot.
6. Utiliza las medidas obtenidas como referencia al preparar maquetas y documentos en un flujo de trabajo parecido al de InDesign.

## Personalizacion

La aplicacion funciona como un sitio de una sola pagina, por lo que los ajustes habituales se realizan desde sus propios controles. Para el uso basico no hace falta crear ni mantener un archivo de configuracion complejo.

Si vas a adaptar el proyecto, revisa el HTML principal y los scripts relacionados. En ellos puedes modificar:

- los presets de formato
- los valores iniciales de los margenes
- las conversiones tipograficas
- las capas visibles del canvas
- los textos de ayuda y las equivalencias
